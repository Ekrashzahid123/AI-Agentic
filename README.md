# Apex AI Arabia — Junior AI Agent Engineer Assessment

Welcome to the repository for the **Junior AI Agent Engineer Technical Assessment** at Apex AI Arabia.

The complete assessment project is located in the [`junior-ai-agent/`](./junior-ai-agent/) directory.

---

## Quick Start Guide

### 1. Navigate to the project directory:
```powershell
cd junior-ai-agent
```

### 2. Install dependencies:
```powershell
pip install -r requirements.txt
```

### 3. Run the automated tests:
```powershell
pytest -v
```

### 4. Run the FastAPI server:
```powershell
uvicorn main:app --reload
```

### 5. Access Interactive Swagger UI:
Open: **[http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)**
